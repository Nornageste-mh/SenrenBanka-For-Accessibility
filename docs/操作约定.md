# 《千恋＊万花》操作约定

> 依据：`docs/操作逻辑公约.md`（第 0 条纪律的一部分）、`docs/交互形态纪律.md`。
> 本文写**本作补丁实际提供什么、不提供什么**；未实测的条目标注「待实机验证」。
> 版本：0.2.0.0（2026-11-13）；引擎 KiriKiri Z（krkrz 1.2.0.3，32 位），补丁是 V2Link 原生插件。
>
> **0.2.0.0 起没有「导航模式」**：界面出现即可用方向键浏览、回车激活，
> 不需要先按 Tab 或任何模式键。`Tab` / `Home` / `End` / `PgUp` / `PgDn` 不再使用。

## 1. 采用情况（对应公约）

| 项目 | 本作采用情况 | 说明 |
|---|---|---|
| 界面键盘控制来源 | **C 类：制造** | 游戏没有控件树、没有焦点链；补丁枚举 KAG 层树，自己维护「当前朗读项」索引 |
| 判定结论 | **B + C（主体 C）** | 剧情操作沿用游戏原生键；界面控制是补丁补出来的 |
| 界面键盘入口 | `NavKeyDown` → 枚举/移动 → `NavActivate` | 见 §2；不再有「进入/退出导航模式」 |
| 激活级别 | **第 1 级：走游戏自己的动作** | 直接调层自己的 `onMouseDown` / `onMouseUp`；剧情推进调 `SystemAction._click()`；启动「注意」声明**不需要点击**（约 2 秒自动淡出，补丁只吞键，见 §3） |
| 遗留导航模式 | **否（0.2.0.0 起移除）** | 0.1.x 的 Tab 模式已删除；旧文档/旧视频里的「先按 Tab」全部作废 |
| 判定文件 | `docs/交互形态判定.md` | 逐界面清点、反模式自查、遗留缺陷都在那里 |

## 2. 键位与操作

### 2.1 朗读与剧情

| 键 | 作用 | 备注 |
|---|---|---|
| `Backspace` | 重读 | 文本态念上一句台词；界面上念当前选中项 |
| `1`–`9` | 选项界面直选第 n 项 | 只在有选项时生效；`0` = 停止朗读（全局沉默） |
| `Alt+Shift+F9` | 切换语音后端 | 顺序：自动 → Tolk → NVDA → 争渡 → SAPI；可在 `plugin\a11y_speech.ini` 的 `key=` / `backend=` 覆盖 |
| `Ctrl`（按住） | 快进（游戏原生） | 补丁不拦截；快进遇选项会停并把选项念出来（约 2.5 句/秒） |
| `Space` / `Enter` | 推进剧情（游戏原生语义） | 文本态由补丁调 `SystemAction._click()` 推进一句；实测每次按键恰好 +1 句，无双推进 |

### 2.2 界面操作（无模式键）

| 键 | 作用 | 备注 |
|---|---|---|
| `↑` / `↓` | 在界面项之间移动 | 文本态按 `↓` 落到第一项、按 `↑` 落到最后一项；首尾循环 |
| `Enter` / `Space` | 激活当前项 | 文本态 = 推进一句；界面态 = 调该层自己的点击处理 |
| `Esc` | 清掉选中，回到文本态 | 有选中时念「回到文字」；没有选中项时**不拦截**，原样交还游戏（例如关游戏菜单） |
| `Backspace` | 重读当前项 | 界面态念选中项；文本态念上一句 |
| `←` / `→` | 仅当选中的是滑条时生效 | 一步约 ±10%（点游戏滑条两端），不跳到点击位置；部分滑条当前值读不出 |
| `0` | 停止朗读 | 全局沉默；再按任意操作键恢复播报 |
| `Tab` / `Home` / `End` / `PgUp` / `PgDn` | **不再使用** | 0.2.0.0 删除；界面里用 `↑`/`↓` 循环即可 |

界面朗读时机：界面出现/切换后约 0.4–0.5 秒内自动播报「界面已更新，共 N 项」，
之后按 `↓` 逐项念「名称。n / N」。界面列表每次由游戏层树重新枚举，
不缓存、不画框、不改游戏状态。

### 2.3 游戏原生占用键（补丁不改变其作用）

| 键 | 游戏原生作用 | 补丁处理 |
|---|---|---|
| `Space` / `Enter` | 推进剧情、确认 | 文本态补丁调游戏动作推进一句（效果一致）；界面态用于激活 |
| `Ctrl`（按住） | 快进 | 不拦截 |
| `R` | 打开历史/回想 | 不拦截 |
| 鼠标 | 点击、滚轮 | 不拦截 |
| `F12` | Steam 截图（平台功能） | 不拦截 |

### 2.4 语义限制（提供与不提供）

| 语义 | 状态 | 说明 |
|---|---|---|
| 界面内的「0 = 沉默」 | 提供（全局） | 按 `0` 停朗读；再操作恢复 |
| 游戏原生确认框 | 部分由游戏提供 | 读档 / 覆盖存档会弹游戏自己的确认框（2026-11-13 冒烟）；删除存档是否二次确认尚未单独验证 |
| 焦点恢复 | 不提供 | 界面每次出现从第一项开始念；不记忆上次位置 |
| 剧情中纯键盘唤出工具栏（QuickMenu） | **不提供** | 游戏靠 OS 光标位置显隐；鼠标移到屏幕底部会弹出（21 项可用 `↑`/`↓` + `Enter` 操作）；替代做法见 §2.5 |

### 2.5 游戏按键绑定页的捕获态（已知差异）

游戏设置 → 键盘页可以给「存檔 / 讀取 / 設定 / 回想」等动作绑定原生键。但补丁在窗口过程里会
先消费方向键、回车、空格，所以**在这个页面按方向 / 回车 / 空格改键没有反应**；请改用
**字母键或功能键**（`A`–`Z`、`F1`–`F24` 等）。绑好的键由游戏自己的 DirectInput 接收，
玩家正常游玩时按这些键会走游戏原生动作。相关遗留见 `docs/交互形态判定.md` §5。

## 3. 页面清单（补丁覆盖到哪里）

| 界面 | 控件从哪里来 | 激活方式 | 朗读 | 覆盖程度 |
|---|---|---|---|---|
| 标题菜单 | 层树枚举按钮层（按层名过滤） | 层 `onMouseDown`+`onMouseUp` | 名称。n / N | dev-fix4/5 冒烟：7 项（Language / 新遊戲 / 讀取進度 / 繼續遊戲 / 流程圖 / 系統設置 / 關閉），`↑`/`↓` 环绕，`Enter` 进正片 |
| 剧情对话 | 游戏原生输入 + `currentInfo` | 补丁调 `SystemAction._click()` 推进一句 | 台词（说话人 + 文本）；有配音只放配音不叠 TTS | dev-fix4/5 冒烟：每次按键 +1 句；`Backspace` 重读当前句；`Esc` 清选中念「回到文字」；剧情态数字键无动作 |
| 剧情选项 | `kag.selectLayer.selects[i]` | `1`–`9` 直选，或 `↑`/`↓` + `Enter` | 选项全文并编号 | 历史版本实机验证；0.2.0.0 尚未逐项复测 |
| 存读档 | 层树枚举槽位层（`enabled==1` 才可操作） | 层事件；读档经确认框 yes/no | 槽位信息 | dev-fix4/5：存檔 33 项 / 讀檔 32 项，槽位带章节与时间；新建 / 覆盖（含确认框）/ 读档全部成功；dev-fix5：读档后不再出现第 22 项、不重复播报「介面已更新，共 22 項」 |
| 设置 | 层树枚举页签/开关/滑条 | 页签与开关走层事件；滑条 `←`/`→` 一步约 ±10% | 选项名；滑条播报真值；显示类当前值多数读不出 | dev-fix4/5：37 项、8 个页签（鍵盤页 58 项）；滑条真值可听（主音量 100%→90%→80%→70%）；「背景語音 2（滑條）」能调但读不回值，念「已調整」 |
| 画廊 / 回想 | `SystemAction._vsave()` 打开的层树 | 层事件 | 缩略图名称/位置 | 可枚举、可激活、不报错；点击后效果未逐项人工确认 |
| 确认框 | 模态层树（yes / no） | 层事件 | 按钮文本 | dev-fix4/5：清单只列对话框自己的项（是/否/確定），不混底层槽位；按「是」完成覆盖/读档；dev-fix5：只剩 3 项（是/否/確定），标题 / 正文层不混入 |
| 流程图 | 层树节点 | 层事件 | 节点名 | 尚未逐项实测 |
| 历史 / 回想文本 | 游戏自己的 `kag.historyLayer` | 游戏原生 `R`；补丁只读 | 逐句 | 历史版本实机验证 |
| 启动「注意」声明 | 整屏预渲染图（不是 KAG 层） | **不需要操作**：约 2 秒自动淡出；补丁只吞 `Enter`/`Space`，不合成点击 | 固定提示「目前畫面是一段無法朗讀的聲明，約兩秒後會自動關閉，不需要操作。」 | 2026-11-13 实测自动淡出；随后约 40 秒到标题 |
| 工具栏 QuickMenu | 靠 OS 光标位置显隐 | **不提供**键盘唤出；出现后可用 `↑`/`↓` + `Enter`（21 项） | 动作名。n / N | 鼠标移到屏幕底部唤出；替代：游戏内设置 → 键盘页绑「存檔 / 讀取 / 設定 / 回想」等原生键 |

> 控件枚举规则（写清楚避免误解）：递归遍历游戏层树，取「可见（`visible==1`）、
> 尺寸合理（>0 且非整屏容器）、自己挂了 `onMouseDown` 层事件」的层，按阅读顺序
> （先上后下、先左后右）排序，按层名 + 矩形去重，排除 `ParentHackLayer`、
> 滚动条、装饰条、`*_rail` 等噪声层；`enabled==0` 的项仍列出但朗读「不可用」。

## 4. 焦点、朗读与撤销

- **没有游戏焦点**：补丁维护的「选中项」只是朗读索引（`g_sel`），
  不画 UI、不改游戏对象状态；`g_sel = -1` 即文本态。
- **朗读跟随操作**：移动一项念一项；界面出现时先念「界面已更新，共 N 项」，
  避免在补丁还没列完清单时误按。
- **离开界面**：界面关闭或切换到文本态时清空选中；`Esc` 在无选中时交还游戏。
- **重复朗读**：`Backspace` 按当前状态重念（选中项 / 上一句）。
- **按实测行为**：界面出现先念「界面已更新，共 N 项」，移动念「名称。n / N」；`Esc` 清选中念「回到文字」；启动封面念「目前畫面是一段無法朗讀的聲明，約兩秒後會自動關閉，不需要操作。」（2026-11-13 dev-fix4/5 冒烟）
- **扫描与激活**：补扫待定期间按 `Enter` 会在补扫完成后继续激活；界面刚切换的那一拍只播报、不激活（有意防误触；dev-fix5）。
- **撤销**：插件被卸载/游戏退出时停止定时器与朗读，不残留键鼠钩子。
