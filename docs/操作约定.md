# 《千恋＊万花》操作约定（逐作填写）

> 依据：`docs/操作逻辑公约.md`（Framework 0.2.7.3 起）。
> **P0 起草、P3 定稿、P4 用测试问卷核对。**
> 只写本作的实际值；与公约默认不同的每一处都要给原因，不许只写「游戏不同」。
>
> 本作引擎是 KiriKiri Z（krkrz），没有 Unity 的 EventSystem / Selectable；
> 下面的「键位」全部指补丁在游戏窗口过程里实际处理的键。

## 1. 采用情况

- 交互形态判定：□ A □ B ☑ **C**（结论见 `docs/交互形态判定.md` §1）
- 界面键盘来源：**制造**（游戏没有界面焦点模型；补丁自己枚举可点层、维护选中项）
  - 入口方法：`NavKeyDown`（`src/a11y6.cpp` 约 2830–2928 行）→ `ScanItems`（约 2093–2265 行）
    → `ClickLogical`（约 2268 行，向游戏窗口发 `WM_MOUSEMOVE` + `WM_LBUTTONDOWN/UP`）
- 激活级别（公约 §2）：□ 1 直接调游戏动作方法 ☑ **2（按本作等价物）** □ 3 只读扫描 + 编号
  - 说明：本作没有 Unity 事件链，第 2 级对应「让游戏自己的命中测试/点击派发处理这次点击」，
    即补丁发真实鼠标消息、由游戏自己决定点中了谁。第 1 级（直接调游戏动作函数）本轮探针已打通（`layer.onMouseDown`+`layer.onMouseUp` 局部坐标；`SystemAction._click/_save/_option/...`；`kag.menu` 项的 `command`），但本版尚未迁移，见 `docs/交互形态判定.md` §1 证据第 5 条。
- 是否使用遗留导航模式：☑ **是（遗留）** □ 否
  - 为什么无法避免：游戏没有界面选中态，补丁必须自己维护「当前项」；第 1 级入口虽已打通，但完整迁移与逐界面读屏验收没做，
    本版只能保留 `Tab` 进出 + 网格扫屏 + 合成鼠标，列为 0.3.0.0 第一件事。
  - 登记位置：`docs/交互形态判定.md` §5（X1/X2/X4/X6/X9 行）；README 与安装说明单列「遗留」。

## 3. 页面清单与控件来源

> 禁止写「扫全部 Selectable」；控件必须来自游戏自己的字段 / 页面对象 / 真实处理器类。

| 界面 | 控件来源（游戏字段 / 页面清单 / pointer-handler） | 原生导航是否可用 | 补丁补了什么 | 未覆盖项 |
|---|---|---|---|---|
| 标题菜单 | 层树枚举（`kag.primaryLayer` → `SystemBaseLayer` / 标题层 `children`），按层名 + `onClick` 过滤 | 否 | 选中项、朗读、合成点击 | 语言切换后需重扫（已做 800ms 节流） |
| 存读档 | 层树枚举 + 存档 API `getBookMarkPlayTime(n)` 判有无存档；`EnrichSaveSlots` 补「存档名+时间+章节」 | 否 | 槽位朗读、翻页 | 翻页按钮标签部分不全；无删除确认 |
| 设置 | 页面模型：`Current.page = 0..7`、每条选项 `Current.cmd(...)`；控件仍靠网格扫屏找层 | 否 | 选项朗读、滑条按百分比调 | 当前值读不出；滑条不念实际值 |

| 选项 | 游戏 `selectLayer.selects`（`.text`/`.plaintext`），判据用「有没有假名」区分台词/选项 | 否 | 编号朗读、`1`–`9` 选择 | 选项与台词语义相反，已用假名判据 |

| 历史 / 回想文本 | 游戏 `kag.historyLayer.currentInfo` 的 `.disp`/`.text`/`.plaintext` | 是（`R` 打开） | 朗读历史 | 无 |

## 4. 焦点、朗读与撤销

- 进入页面时初始焦点由谁设置：**补丁自己**（扫描完成后取阅读顺序第一项并朗读；
  游戏没有焦点可继承 —— 遗留缺陷，见判定 §5 X2）
- 是否抑制程序化焦点造成的重复播报：☑ 是（清单内容变化才播报，避免每次重扫重复念）
- 离开页面时焦点恢复方式：**清空补丁自己的清单与选中项**，交还游戏；
  游戏没有焦点生命周期可走（遗留缺陷）
- 延迟朗读的取消条件：重新扫描排期（+150/+400/+700ms）时取消旧播报；
  界面关闭/切换时丢弃未播完的旧项；快进中不播报
- 输入订阅 / 事件订阅 / 焦点恢复在页面销毁时是否撤销：☑ 是
  （`V2Unlink` 停定时器、解窗口子类、释放后端；无长期挂载）
