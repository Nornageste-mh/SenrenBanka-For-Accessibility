## 5. 遗留缺陷

| 缺陷 | 玩家会感知到什么 | 现状 |
|---|---|---|
| 剧情中工具栏（QuickMenu）纯键盘唤不出 | 想用键盘开存读档/设置/回想时找不到入口 | 游戏靠 OS 光标位置显隐（鼠标移屏幕底部出现，21 项可键盘操作）；替代：设置 → 键盘页把「存檔/讀取/設定/回想」绑到字母/功能键 |
| 游戏按键绑定页捕获态 | 想给游戏动作改键时，按方向/回车/空格没反应 | 补丁先消费这些键；改键请用字母/功能键，绑好后物理键走游戏 DirectInput |
| 滑条一次只走 ±10%，个别滑条值读不回 | 调音量/速度要按多次；「背景語音 2（滑條）」只念「已調整」 | 多数滑条已能播报真值（主音量等）；读不回的那几项继续研究 |
| 画廊 / 回想缩略图点击效果未逐项人工确认 | 不知道点开没点开 | 可枚举、可激活、不报错；效果待人工确认 |
| 画面显示页 / 鼠标页 / 确认页只验证可枚举 | 这三个页的个别控件行为可能与预期不同 | 本轮冒烟重点是主流程，未逐项操作 |
| 设置显示类选项当前值读不出 | 念得出选项，念不出当前选的哪个 | 只有 7 项可读（`afterskip`/`afterauto`/`voicecut`/`voicecutpage`/`bgmdown`/`noeffect`/`sysnoeffect`） |
| 自动/快进与新按键的交互未验证 | 快进中误按方向键/回车行为待确认 | 待实机 |
| 部分按钮标签不四语齐全 | 个别按钮退回中文或位置说法 | 补层名映射 |
| 争渡真实出声未实机（`Alt+Shift+F9` 切换已实测） | 只装争渡的机器可能没声音 | 桩自检已过，等真机 |

**接手须知**：

- 这是 **KiriKiri Z 原生插件**，没有 Unity 平台层、没有 `Assembly-CSharp`、没有 `LogOutput.log`、没有 `winhttp.dll`；别套 BepInEx 的调试/卸载流程。
- `data.xp3` 内层索引必须逐字节照抄（涉及 G37 条目）；用哈希重建会静默丢 storage，症状是 `Cannot convert the variable type ((void) to Object)`。
- 构建有 32 位硬断言；`A11Y_DEV` 只存在于开发构建，发布构建里没有开发通道。
- `docs/DESIGN.md` 是历史技术文档，个别表述与现状有出入时，以本文与实测为准（尤其加载路径、交互形态两处）。
- **不要动**：语音后端降级顺序与 ZDSR 硬细节；注入器的内层索引处理；`A11Y_DEV` 开关语义；发布构建的开关状态。这些都有实测/发布约束，改之前先查证据。
- 不 commit 逆向产物、`.xp3`、`.sig`、日志与截图（`.gitignore` 已拉黑）。
