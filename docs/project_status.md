## 1. 项目概况

- 游戏 / 引擎 / 技术栈路线：**KiriKiri Z（krkrz 1.2.0.3，32 位）原生 C++ V2Link 插件**
  （`a11y.dll`，单文件 `src/a11y6.cpp`）。不是 Unity / BepInEx / IL2CPP。
  游戏：《千恋＊万花》Senren＊Banka，Steam AppID 1144400，YUZUSOFT 开发。
- 安装与还原方式：**安装会改游戏文件**——替换 `data.xp3`（约 985MB，先在启动脚本槽位注入
  `Plugins.link("a11y.dll")`）+ 拷 `plugin\` 文件；**唯一还原手段是事先备份的 `data.xp3.bak`**
  （加法模式，不允许二次修改）。详见 `docs/RESTORE.md` 与 `docs/DESIGN.md` §16。
- 设计依据：作品根的 `无障碍可行性验证.md`、`docs/交互形态判定.md`、`docs/操作约定.md`。
- 公开资料检索：**尚未系统检索**（见 `无障碍可行性验证.md` §0.1，待补；键位/界面结论全部来自
  本机实测与源码）。
- 测试便捷通道：**无**（未发现游戏自带开发者面板/调试控制台；发布包不含测试跳转）。
  开发期取证用插件的开发构建（REPL 命令通道 + 诊断日志，编译期开关 `A11Y_DEV`，
  **发布构建里不存在**；见 §2「开发通道」）。
- 操作语义：与 `docs/操作逻辑公约.md` 一致，差异逐条见 `docs/操作约定.md`；
  **遗留导航模式（`Tab`）仍在**，不是「操作已统一」的合规范本（判定 C 类遗留）。
- 构建入口：`build/build.cmd`（默认 release；`build\build.cmd dev` 为开发构建）；
  提交前守卫：`tools/check-staged.ps1`；发布：`tools/make_release.ps1`。
- 发布状态：**已部署待实机**（0.1.0.6 pre-release 已在 GitHub 发布；0.2.0.0 为本次
  文档/治理对齐版本，尚未实机验收）。
