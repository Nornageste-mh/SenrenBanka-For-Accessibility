# 《千恋＊万花》无障碍补丁 安装说明

> 本文件在发布包 `SBA11y-<版本>-installer.7z` 的根目录，与 `README.md`、`CHANGELOG.md`、
> `常见问题.md` 放在一起。逐作重写；通用问题见 `常见问题.md`。

## 这是什么

- 给 Steam 正版《千恋＊万花》（Senren＊Banka，AppID 1144400）用的**非官方**屏幕阅读器补丁。
- 它让游戏把台词、选项、界面控件名称交给读屏软件念出来，并让界面可以用键盘操作。
- **只面向已经在 Steam 购买本作的玩家。** 请支持正版。
- **安装会改游戏文件**：替换 `data.xp3`（约 985 MB）并往 `plugin\` 放几个文件。
  **这是本作引擎的限制，不是我们想改**：引擎不会自动加载 `plugin\*.dll`，
  唯一能在插件加载前执行到补丁代码的位置，就是 `data.xp3` 里的启动脚本槽位。
- 发布包**不含任何游戏文件**；改好的归档由注入工具**在你自己的机器上、用你自己的原档**生成。

## 装之前

1. 确认是 **Steam 正版**，并且游戏能正常启动一次。
2. 关掉游戏（补丁是游戏内插件，游戏运行时替换归档会失败）。
3. 留出约 **2 GB** 磁盘空间（原档 + 生成的新档）。
4. **先备份**：把游戏目录里的 `data.xp3` 复制/改名为 `data.xp3.bak`。
   **这是唯一的还原手段**，请务必做。

## 安装（分步）

1. 双击发布包里的 `tools\注入工具.exe`，选择你游戏目录里的 `data.xp3`。
   它会生成 `data.patched.xp3`（约 985 MB，约 4.5 秒）。
2. 退出注入工具；把 `data.patched.xp3` 改名为 `data.xp3`，覆盖原来的文件。
3. 把发布包 `plugin\` 里的文件拷进游戏的 `plugin\`：

   ```
   <游戏目录>\plugin\a11y.dll
   <游戏目录>\plugin\nvdaControllerClient.dll      ← 随包提供（NV Access 官方 x86 版）
   <游戏目录>\plugin\ZDSRAPI.dll                   ← 随包提供（争渡 32 位，兜底用）
   <游戏目录>\plugin\ZDSRAPI_x64.dll               ← 随包提供（争渡 64 位，兜底用）
   <游戏目录>\plugin\a11y_labels.ini               ← 可选，覆盖内置标签
   <游戏目录>\plugin\a11y_labels_{jp,en,tw}.ini    ← 可选，其它语言的标签
   <游戏目录>\plugin\a11y_speech.ini               ← 可选，语音后端配置
   ```

   `ZDSRAPI*.dll` 不用管：装了争渡就读它安装目录那份，包内这两个只是兜底，删掉不影响功能。
4. 启动游戏。读屏软件应当念出「无障碍模块已加载，语音后端 ……」。
   如果没听到，先看 `常见问题.md`。

## 三条坑（务必知道）

1. **`data.xp3.bak` 千万别删**。还原只能靠它整包恢复；改过的归档不允许二次修改。
2. **游戏路径不要含中文**（注入工具与部分读屏 DLL 对中文路径处理不好），
   路径也不要用 OneDrive 之类的同步目录。
3. **不要用 Steam 的「验证游戏文件完整性」**：它会把 `data.xp3` 换回原版，
   补丁随之失效（存档不受影响，重新注入即可）。

## 已装过旧版本

- 直接按上面的步骤重新注入一次，覆盖 `plugin\` 文件即可；
  旧版的配置（`plugin\a11y_speech.ini`）会保留，键位会沿用它。
- 从 0.2.0.0 起，**语音后端切换默认键从 `F9` 改成 `Alt+Shift+F9`**。
  如果你的旧配置里写着 `key=F9`，改 `key=Alt+Shift+F9` 或删掉该行即可。

## 卸载 / 还原

1. 把 `data.xp3.bak` 改名回 `data.xp3`（覆盖当前文件）。
2. 从游戏 `plugin\` 删掉 `a11y.dll`、`nvdaControllerClient.dll`、`ZDSRAPI*.dll`、
   `a11y_labels*.ini`、`a11y_speech.ini`（只删补丁放进去的那几个，别删游戏自带的）。
3. 补丁不改游戏本体逻辑，**不会留下残留**。完整步骤见发布包内 `README.md` 的「还原」一节。

## 快捷键

### 朗读快捷键（补丁新增）

| 键 | 作用 |
|---|---|
| `Backspace` | 重读：文本态念上一句台词（有配音台词也带说话人重读）；界面态念当前选中项 |
| `1`–`9` | 有选项时：直接选择第 n 项 |
| `0` | 停止朗读（全局沉默）；再按任意操作键恢复 |
| `Alt+Shift+F9` | 循环切换语音后端（自动 → Tolk → NVDA → 争渡 → SAPI），念出结果 |

### 界面操作（没有模式键）

界面一出现，方向键就能用，**不需要先按 `Tab`**（0.2.0.0 起删除了旧的导航模式）：

| 键 | 作用 |
|---|---|
| `↑` `↓` | 上一项 / 下一项，念出「名称。n / N」；首尾循环 |
| `Enter` / `Space` | 激活当前项；文本态 = 推进一句剧情 |
| `Esc` | 清掉选中、回到文本态；没有选中时不拦截，交还游戏 |
| `Backspace` | 重读当前项 / 上一句 |
| `←` `→` | 仅当选中的是滑条时生效：一次约 ±10%（不跳到点击位置） |
| `Tab` / `Home` / `End` / `PgUp` / `PgDn` | **不再使用**（旧版遗留，已删除）；长列表用 `↑`/`↓` 循环 |

界面出现/切换后约 0.4–0.5 秒会自动播报「界面已更新，共 N 项」。

同屏出现多个界面时只操作**最上层**（0.2.0.1 遮挡过滤）：设置盖住标题时，标题按钮不会被念到或激活。

启动封面那段「注意」声明**不需要按键**：无输入时约 2 秒自动淡出（实测），
随后约 40 秒自动到标题；补丁只吞 `Enter`/`Space`，不代点、不合成鼠标点击。

**剧情中的工具栏（QuickMenu）**：补丁**不能**纯键盘唤出它（游戏靠鼠标位置显隐）。
把鼠标移到屏幕底部可让它出现，出现后 21 项都能用 `↑`/`↓` + `Enter` 操作。
替代做法：游戏设置 → 键盘页，把「存檔 / 讀取 / 設定 / 回想」等动作绑到原生键。

**在游戏设置 → 键盘页改键时**：方向 / 回车 / 空格会被补丁先吃掉，按了没反应；
请改用**字母 / 功能键**（`A`–`Z`、`F1`–`F24` 等）。绑好后物理键走游戏自己的 DirectInput，
正常游玩时会执行对应动作。

### 游戏原生占用键（补丁不抢）

`Space`、`Enter`（含小键盘）、按住 `Ctrl`、`R`、鼠标（移动/左键/滚轮）、`F12`（Steam 截图）。
这些键的原有作用不变；补丁不把它们拿来当重读键。文本态下 `Enter`/`Space` 由补丁调游戏自己的
推进动作（`SystemAction._click()`），效果与原生一致，实测不双推进。

## 配置

配置文件：`plugin\a11y_speech.ini`（UTF-8，可选；不写就用默认值）。

```ini
key=Alt+Shift+F9     # 切换语音后端的键；主键限 F1..F24、A..Z、0..9
backend=auto         # auto / tolk / nvda / zdsr / sapi，也可写「自动」「争渡」
```

- 改 `key=` 后重开游戏生效；`backend=` 由插件自己维护。
- 后端不可用时会自动回退到自动链上的其它后端，不会静默变成「没有声音」。

## 实测数字（本作，发版前请重测）

- 注入耗时：约 4.5 秒；生成归档约 985 MB。
- 快进速度：引擎自节流约 400 ms/句（实测）。
- 语音后端：本机以 NVDA 实测可出声；争渡后端仅桩 DLL 自检（85 项）与只读握手，
  **未在真实游戏里验证出声**。
- 启动封面：无需操作，约 2 秒自动淡出（2026-11-13 实测）；补丁不代点、不合成鼠标。
- 界面操作（2026-11-13 dev-fix4/5 + 0.2.0.1 实机冒烟）：标题菜单 7 项、`↑`/`↓` 环绕、`Enter` 进正片；
  剧情每次按键 +1 句、`Backspace` 重读、`Esc` 清选中念「回到文字」；设置 37 项 / 8 个页签
  （键盘页 58 项），滑条 `←`/`→` 播报真值（主音量 100%→90%→80%→70%），「背景語音 2（滑條）」读不回值
  （dev-fix5 别名已改繁体）；
  存檔 33 项 / 讀檔 32 项，槽位带章节与时间，新建 / 覆盖（含确认框）/ 读档全部成功；
  确认框只列对话框自己的项（dev-fix5：只剩 3 项「是/否/確定」，标题 / 正文层不混入）；
  读档后不再出现第 22 项、不重复播报「介面已更新，共 22 項」；工具栏 QuickMenu 出现时 21 项可操作；
  `Alt+Shift+F9` 切换语音后端成功；dev-fix5 复测 4 项修复通过（确认框 3 项、别名繁体、
  `MusicTitlePopupTip` 装饰层排除、补扫期间 `Enter` 不吞）。最终 release 构建与 dev 同源（只差诊断开关）。
- 0.2.0.1 实机（dev）：同屏遮挡时只收最上层（设置盖标题时标题 7 项全丢、设置自身 36–37 项）；
  工具栏出现/消失后 `Backspace` 仍能重读有配音台词（带说话人）；流程图界面会念到原始层名（已登记遗留）。
- 仍未由玩家用读屏做逐界面验收；画廊点击效果、画面显示 / 鼠标 / 确认页逐项操作未验证。
  其余界面见 `README.md`「交互形态判定摘要」。
