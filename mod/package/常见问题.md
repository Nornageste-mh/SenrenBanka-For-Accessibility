# 常见问题（FAQ）

> 发布包内通用文档，跨作品复用；本作的差异在问题里单独标注。
> 安装步骤见 `安装说明.md`。

## 装了没反应，读屏一声不响

1. 确认游戏 `plugin\` 里有 `a11y.dll`，且是 **32 位**版本（本作游戏是 32 位）。
2. 确认 `data.xp3` 真的注入过：注入后应当约 985 MB，且启动时会念
   「无障碍模块已加载，语音后端 ……」。没听到这句话，多半是归档没替换成功。
3. 确认读屏软件正在运行（NVDA / 争渡），且补丁能找到它。
   用 NVDA 的话，`nvdaControllerClient.dll` 必须在 `plugin\` 里。
4. 看 `plugin\a11y_speech.ini` 的 `backend=` 是否写死了一个本机没有的后端；
   删掉这一行恢复自动。

## 念了「语音后端不可用」

说明候选后端都没通过自检（dll 找不到 / 未授权 / 版本不匹配）。补丁会念出试过的路径。
常见原因：

- 装的是争渡但没启动、或未授权；
- `ZDSRAPI.dll` 版本与争渡安装目录那份对不上（补丁会自动换下一份候选）；
- NVDA 启动得比游戏晚（补丁会每 5 秒重试，等一会儿或重开游戏）。

## 注入工具打不开 / 报错

- **游戏必须完全退出**（包括后台残留进程）。
- 确认选中的是**原版** `data.xp3`，不是已经注入过的版本（注入过的再注入会失败）。
- 路径不要含中文、不要放 OneDrive 同步目录。
- 杀毒软件可能误报注入工具（它要改 1 GB 归档）；加白名单或临时关闭后再试。

## 注入后游戏打不开 / 黑屏 / 闪退

1. 用备份 `data.xp3.bak` 换回 `data.xp3`，确认游戏能正常启动。
2. 再注入一次；中途不要中断（注入过程会写约 985 MB）。
3. 仍不行：把 `plugin\a11y.dll` 先移走再启动——如果游戏正常，说明是插件问题，
   请反馈补丁版本与系统信息。

## 我的存档还在吗？怎么还原？

存档在游戏自己的 `savedata\` 里，补丁**不碰存档**。还原方法：
`data.xp3.bak` 改回 `data.xp3`，再从 `plugin\` 删掉补丁文件。
**千万不要用 Steam「验证游戏文件完整性」来还原**——它会把归档换回原版，
但补丁文件还在，容易造成半装状态；按上面的步骤做更干净。

## 朗读和游戏语音叠在一起

补丁默认**不给有配音的台词再叠 TTS**（人声已经在读）；想重听当前句按 `Backspace`。
如果仍然叠音，检查读屏软件是否开了「朗读屏幕上的文字」之类的功能（本作界面是图层，
读屏看不到文字，一般不会触发）。

## 快进的时候不朗读

快进（按住 `Ctrl`）时补丁刻意不逐句朗读，避免刷屏；松开 `Ctrl` 后会补念当前句。
遇到选项会自动停止快进并把选项念出来。

## 按钮念不出名字 / 念的是位置

部分界面（存档翻页、自定义按钮排列、记忆界面）的标签还没有四语齐全，会退回中文或
「第 N 项」的位置说法。这是已知缺陷，见 `README.md`「交互形态判定摘要」。

## 为什么界面要先按 Tab 才能操作？

这是本作的**历史遗留做法**：游戏界面没有 Windows/Unity 那种焦点模型，补丁早期只能
自己造一个「导航模式」。**它不是推荐做法**，框架的默认约定是界面一打开键盘就能用。
0.3.x 会尝试去掉它；在那之前请先按 `Tab`，见 `安装说明.md` 的「界面操作」。

## 为什么没有「按一下就读出整个界面」的功能？

本作界面文字是**按语言预渲染成图片**的，没有可直接读的文本表；补丁只能逐项朗读
控件名称，不能整屏读。这是游戏本身的限制。

## 会被封号吗？能用盗版吗？

补丁是本地单机游戏的进程内插件，不联网、不改账号数据；但**任何第三方工具都有风险**，
请自行判断。**本补丁只面向 Steam 正版玩家**，不提供也不支持盗版用途。

## 能不能不改游戏文件？

不能。本作引擎不会自动加载 `plugin\*.dll`，唯一可靠的加载入口在 `data.xp3` 的启动脚本里；
外挂补丁档、散装脚本等 13 种非破坏性方案都实测过，全部不生效。详见
`README.md` 与 `docs/DESIGN.md` 第 16 节。
