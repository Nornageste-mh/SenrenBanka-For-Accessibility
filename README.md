# senren-banka-a11y

给《千恋＊万花》做的**无障碍模式**：让主流读屏软件能念出剧情与界面，并且用**标准 Windows 辅助功能接口**和**标准键位**操作，而不是给某一个读屏软件写私有适配。

- 当前版本：**0.0.0.5**（见 `CHANGELOG.md`）
- 目标平台：Windows x86（游戏是 32 位 krkrz 1.2.0.3 / KiriKiri Z）
- 游戏本体、资源、脚本、存档**不在本仓库内，也不会入库**（见下面的「内容边界」）

---

## 它做什么

模式是一个 **V2Link 插件**（`a11y.dll`），由游戏进程自己加载，因此：

1. **文字直接进读屏 DLL** —— 不另起进程、不走管道、不开伴随窗口。
   语音后端链：`Tolk`（若游戏目录有 `tolk.dll`）→ `nvdaControllerClient.dll`（NV Access 官方 x86 构建）→ `SAPI5`（纯 vtable 调用，不走 COM 后期绑定）。
   任一级失败都只降级，绝不把异常抛回游戏主循环。
2. **界面用键盘导航** —— 控件不是 Win32 控件，就是 KAG 的图层。
   模式自己在窗口过程里接管按键，把「按一下」翻译成对目标控件的**真实鼠标点击**（走游戏自己的派发），所以不需要读屏软件配合。
3. **选项可听可选** —— 选项出现时整块念出来（本地化文本，不是原文），数字键 `1`–`9` 直接选，用的是游戏自己给的按钮矩形。

### 键位

| 键 | 作用 |
|---|---|
| `Tab` | 进入 / 退出导航模式 |
| `↑` `↓` | 选择控件（会念出名称与 `i / N`） |
| `Home` / `End` | 首项 / 末项 |
| `PgUp` / `PgDn` | 前后跳 5 项 |
| `Enter` / `Space` | 激活当前控件（非导航模式下 = 推进剧情下一句） |
| `←` `→` | 调整滑条类控件 |
| `Esc` | 退出导航模式 |
| `Backspace` | 重读上一句 |
| `1`–`9` | 选项场景：选择对应选项 |
| `Ctrl`（按住） | 快进；遇到选项自动停手并把选项念出来 |

游戏本体的原生键位（空格/回车推进、`R` 开历史、按住 `Ctrl` 快进）**不动**，模式不去抢占。

## 内容边界（重要）

本仓库严格遵守一条线：**任何会影响开发商与发行商利益的内容都不入库**。

**入库的**：模式自己的源码、构建脚本、文档，一张界面控件标签表
（`data/a11y_labels.ini`，形如 `topmost_on=总在最前：开` —— 这是功能性 UI 名称，用于让读屏念出中文而不是英文层名），
以及**引擎的**接口头文件 `third_party/tjs2/`（见下）。

`third_party/` 是这条线**唯一**的开口，而且只开口给引擎代码：那是 W.Dee 的 TJS2 / 吉里吉里，
**不是柚子社的资产**，许可里明确允许嵌入别的软件。带上它，别人才能拿到源码就编出一样的产物。

**不入库的**（`.gitignore` 里逐类拉黑，误敲 `git add .` 也拦得住）：

- 游戏本体与资源：`*.xp3` `*.sig` `*.exe` `*.dll` `savedata/` …
- 游戏脚本 / 剧情：`*.ks` `*.scn` `*.psb` `*.tjs` `*.func` …
- 音视频与图片：`*.ogg` `*.png` `*.pimg` …、`shots/`
- **逆向与解包分析脚本、反汇编产物**：XP3 解包、脚本解密、TJS 反汇编、探针转储目录 …
- 运行日志与探针输出（可能夹带剧情文本）

日常诊断日志写在游戏目录外的本地路径，不进仓库。

## 构建

只需要一样外部东西：Visual Studio 的 32 位命令行环境。
编译所需的 TJS2 接口头文件**已经随仓库提供**（`third_party\tjs2`，见 `third_party\README.md`）。

```cmd
set VCVARS="C:\Program Files\Microsoft Visual Studio\...\VC\Auxiliary\Build\vcvars32.bat"
build\build.cmd
```

产物是 `a11y.dll`（导出 `V2Link` / `V2Unlink` / `GetModuleThreadModel`）。
想改用自己的一份头文件，设 `TJS_INC` 覆盖即可。

### 可复现性

用仓库自带的头文件、按上面的脚本构建，产物与作者的构建结果：

- **大小完全一致**（183,296 字节）
- **`.text` 代码段逐字节相同**（差异 0 字节）
- 只有 PE 时间戳与调试目录里的构建路径不同（`.rdata` 里的元数据）

也就是说，落在磁盘上的**代码**是一样的，差异只来自「什么时候、在哪个路径编的」。

### 第三方组件

| 组件 | 许可 | 是否随仓库 |
|---|---|---|
| TJS2 / 吉里吉里 接口头文件（`third_party\tjs2`，11 个文件） | 吉里吉里自有许可 或 GNU GPL（双许可） | **是**，逐字节原样，许可证原文随附 |
| `nvdaControllerClient.dll` | NV Access | 否，安装时自取 |
| Tolk（可选） | LGPL | 否 |

按吉里吉里许可「流用」条款的要求，此处注明：**本模式在编译时使用了吉里吉里 / TJS2 的源码文件**
（见 `third_party\README.md`）。这些文件不属于柚子社，也不含任何游戏内容。

## 安装

游戏**不会自动加载 `.tpm`**，本作是靠启动脚本里的一句 `Plugins.link("a11y.dll")` 拉起来的，
所以安装需要把一个启动槽位替换掉（细节见 `docs/DESIGN.md`）。把产物放进游戏的 `plugin\` 目录：

```
<游戏目录>\plugin\a11y.dll
<游戏目录>\plugin\nvdaControllerClient.dll     ← NV Access 官方 x86 版
<游戏目录>\plugin\a11y_labels.ini              ← 可选，覆盖内置标签表
```

`tools\install_when_closed.ps1` 是个省事的小脚本：等游戏退出（DLL 被占用时换不了），
换掉文件，再重新启动。

## 还原

模式不改动游戏本体逻辑，还原就是删掉上面三个文件、恢复启动脚本。完整步骤见 `docs/RESTORE.md`。
